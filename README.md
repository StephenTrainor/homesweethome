# Home Sweet Home

A simple, intuitive platform to find your next home. Swipe through listings, search by your preferences, and discover places to sublet, rent, or more — all through a clean interface designed to make the hunt feel less like work.

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | Next.js, Tailwind CSS |
| Backend | FastAPI |
| Database | PostgreSQL |
| Auth | Supabase Auth |
